# Ra-udo's Little Adventure

A short, cozy text adventure written from original character design notes.

You play as **Ra-udo**, a 3,852-year-old being from a long-lived people (typical lifespan ~5,000 years). In human terms he is still quite young and loves going on adventures.

## Character Design

- **Appearance**: Three eyes, one ear, five noses, one mouth, three arms, four legs, ten fingers on each hand, seven toes on each foot.
- **Clothing**: Looks almost human but is specially tailored for three arms and four legs.
- **Home**: Nice, cozy, and calm.

### Naming Rules
- Boys’ names end with “du”.
- Girls’ names can end with any syllable except “du”.

### Cast
| Character     | Role                          |
|---------------|-------------------------------|
| **Ra-udo**    | Main character (you)          |
| **Mudu**      | Father – mild, random remarks |
| **MadiMoona** | Mother – appears randomly     |
| **Mani Nudu** | Best friend                   |
| **Ramnundu**  | Wise villager                 |

## How to Play

```bash
python3 raudo_adventure.py
```

The game uses a gentle typewriter effect and numbered choices. Dialogue is randomized, so every playthrough feels a little different. Multiple quiet endings are possible depending on the paths you take.

Requires only Python 3 (no external packages).

## About the Project

This game was built directly from a short design document that focused on character appearance, family, and naming conventions before any plot was written. The story therefore stays light, exploratory, and true to that spirit.

Feel free to fork, expand the world, or add new adventures!
